# Q3 — Kanban Board

Route: `/kanban` · Branch: `feature/q3-kanban`

Build a task board with three columns: To do, In progress and Done.

## Requirements

- Add, edit and delete cards. A card has a title (required) and an optional description.
- Move cards between columns and reorder them within a column by dragging.
- Users who can't use a mouse can still move cards (for example, with the keyboard or a menu).
- Show the number of cards in each column.
- The board survives a page refresh.

## Acceptance criteria

- Moving a card updates both columns and their counts correctly.
- At least one automated test.
